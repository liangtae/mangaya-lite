# Info untuk Pengaturan Repo GitHub

**Nama repo:** `mangaya-lite`

**Description (About, maks. 350 karakter):**
Pembaca komik/manga offline-first dalam satu file HTML. Impor CBZ, ZIP, PDF & gambar, baca mode 1/2 halaman atau gulir, rak koleksi dengan rating, tag, favorit & cadangan. Tanpa server, data tersimpan lokal.

**Versi Inggris (opsional):**
Single-file, offline-first comic & manga reader. Import CBZ, ZIP, PDF and images; read in single, double-page or vertical scroll mode; manage a library with ratings, tags, favorites and backups. No server, all data stays local.
